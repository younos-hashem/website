The site is built using the static site generator [Hugo](https://gohugo.io/) using a modified version of the [Hugo - Classic](https://themes.gohugo.io/themes/hugo-classic/) by Kellen Evan Person. The site's source code can be viewed [on GitHub](https://github.com/younos-hashem/website). I use GitHub Pages and Cloudflare for hosting.

The site's visual design is inspired by the visual designs of Anthropic's Claude and of [Asterisk Magazine](https://asteriskmag.com/) (the latter recently switched from a pleasing red to an ugly blue). I chose a nautilus as the site's logo because (a) it's pretty and (b) its shell, which is a nearly perfect [logarithmic spiral](https://en.wikipedia.org/wiki/Logarithmic_spiral#/media/File:Nautilus_Cutaway_with_Logarithmic_Spiral.png), shows us how mathematical beauty can appear in nature. This is the entire spirit of physics.
